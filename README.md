# Project creation prompt

Attach a copy of AGENTS.md to a new local Codex chat, then paste the prompt below with the bracketed fields filled in. These are reusable setup materials; adding them to this repository does not start the setup.

---

Follow the attached AGENTS.md to build a working local project on this computer.

Project name: [NAME]
Purpose: [WHAT I WANT IT TO DO]
Project information: [FILES, FOLDERS, LINKS, OR DETAILS TO USE]
Required plugins: [PLUGIN NAMES, OR “CHOOSE WHAT IS NEEDED”]

Connect this project to its own dedicated Telegram bot so I can ask questions, request changes, and receive results through Telegram.

Create the project files, organize its information, configure the required integrations, and document their exact locations. Verify that the Telegram agent can access the information and plugins it needs.

Guide me through creating the Telegram bot and entering its token securely on my computer. Ask for missing details when necessary, and continue building everything that does not depend on my answers.
